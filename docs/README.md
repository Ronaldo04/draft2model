# docs

## Overview
Índice de documentación técnica, guías operativas, matrices de requisitos, especificaciones de arquitectura y protocolos de integración del proyecto Draft2Model.

## Subdirectories & Key Documents
- **Guías de Inicio y Reproducibilidad**:
  - [`GUIA_REPRODUCIBLE.md`](GUIA_REPRODUCIBLE.md): Manual paso a paso para instalación offline, configuración de rutas, ejecución de la demo y uso general.
  - [`ACCESOS_Y_PROVEEDORES.md`](ACCESOS_Y_PROVEEDORES.md): Gestión segura de credenciales locales (OpenAI / Gemini) y política de no persistencia en disco.
  - [`CONTEXTO_PROYECTO.md`](CONTEXTO_PROYECTO.md): Alcance general del proyecto, contratos arquitectónicos y definición de terminado.
- **Especificaciones Técnicas y de Diseño**:
  - [`ADAPTADOR_ETABS.md`](ADAPTADOR_ETABS.md): Especificación de la interfaz OAPI COM con CSI ETABS v18+.
  - [`CONTRATO_GEOMETRIA.md`](CONTRATO_GEOMETRIA.md): Formato JSON de entidades geométricas, puntos, segmentos y polígonos.
  - [`COMPATIBILIDAD_PARTICIONES.md`](COMPATIBILIDAD_PARTICIONES.md): Algoritmos para manejo de huecos, aberturas y discontinuidades en losas y muros.
  - [`DEMO_INTEGRADA.md`](DEMO_INTEGRADA.md): Alcance y verificación del flujo sintético sin dependencias externas.
- **Control y Seguimiento**:
  - [`CONTROL_AVANCE.md`](CONTROL_AVANCE.md): Catálogo de criterios e hitos alcanzados.
  - [`MATRIZ_REQUISITOS_REFERENCIA.md`](MATRIZ_REQUISITOS_REFERENCIA.md): Delimitación técnica de evidencias y alcances demostrados.
