# Referencia para la sustentación del programa

Actualizado: 13 de octubre de 2026. **Documento académico de referencia; no es un plan de ejecución.**

## Uso exclusivo

El programa solicita explicar el rol, aporte y área estratégica de cada integrante durante la sustentación final. Este archivo conserva el planteamiento histórico y permite preparar esa explicación con evidencia real.

Los requisitos, hitos y criterios actuales se encuentran en [Plan de operación](PLAN_OPERACION.md). Las reuniones permiten consultar y discutir los cambios.

La distribución inicial no demuestra que una contribución se haya realizado. No debe presentarse como trabajo ejecutado sin evidencias. La exposición final debe distinguir intención inicial, observaciones en reuniones, aportes efectivos y ejecución realizada.

## Preparación de la exposición final

Para cada integrante, describir solo lo acreditado: área del aporte efectivo, intervención concreta, efecto en el proyecto y evidencia. Identificar cuando el rol inicial cambió o no se materializó. Explicar también la ayuda de herramientas de IA y las comprobaciones humanas realizadas, sin atribuirles credenciales ni aprobación profesional.

Este archivo se consulta para la sustentación; no introduce asignaciones, plazos personales, permisos de GitHub ni condiciones para cerrar hitos técnicos.
